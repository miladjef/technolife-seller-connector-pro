# Technolife Seller Connector Pro for WooCommerce

نسخه: 1.2.0

افزونه اتصال ووکامرس به Seller API تکنولایف، شامل:

- اتصال امن به API با `Authorization` و `encrypted-secret`
- تولید `encrypted-secret` با AES-128-GCM، **دقیقاً مطابق الگوریتم رسمی مستند** (IV دوازده‌بایتی، Auth Tag شانزده‌بایتی، خروجی `iv:tag:ciphertext`)
- اعتبارسنجی خودکار طول کلید Secret در پنل (باید پس از Base64 دقیقاً ۱۶ بایت باشد)
- چند حالت Payload برای `encrypted-secret` جهت سازگاری با ابهام مستند
- تست اتصال API
- متاباکس اتصال تکنولایف در صفحه محصول ووکامرس و فیلد اختصاصی برای هر variation
- اتصال محصول/تنوع به `productCode`، `sellerItemCode` و `SalesCode`
- ارسال قیمت به `PATCH /v1/pricing/{sellerItemCode}/info`
- ارسال موجودی به `PATCH /v1/products/{sellerItemCode}/info`
- مخفی/نمایش خودکار تنوع بر اساس موجودی صفر
- **تبدیل واحد قیمت ریال/تومان** (تکنولایف قیمت را به ریال می‌خواهد)
- ارسال قیمت‌ها به‌صورت عدد صحیح ریالی (مطابق نمونه‌های مستند)
- قوانین هوشمند قیمت‌گذاری (درصد کلی، درصد دسته‌بندی، جایگزینی/جمع، بیشترین/کمترین، گرد کردن، کنترل بازه مجاز)
- دریافت سفارش‌ها از `GET /v1/orders/sbs` و جزئیات از `GET /v1/orders/sbs/{orderCode}`
- ادغام داده‌های لیست سفارش با جزئیات (حفظ `status` و `totalPrice`)
- **عدم دریافت تکراری جزئیات سفارش‌های بدون تغییر وضعیت** (کاهش چشمگیر مصرف API)
- ساخت سفارش ووکامرس از سفارش تکنولایف + ذخیره وضعیت در متای سفارش
- امکان کاهش موجودی ووکامرس بعد از ساخت سفارش جدید
- خروجی CSV سازگار با Excel برای محصولات، سفارش‌ها و لاگ‌ها
- لاگ کامل درخواست‌ها و پاسخ‌های API + اجرای مجدد عملیات ناموفق
- کران خودکار همگام‌سازی
- **اعلام سازگاری با HPOS** (جدول سفارش‌های سفارشی ووکامرس)

## نصب

1. فایل ZIP افزونه را از مسیر «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.
2. WooCommerce باید فعال باشد.
3. افزونه را فعال کنید.
4. از منوی «تکنولایف ← تنظیمات اتصال» API Key و Secret Key را وارد کنید.
5. تست اتصال API را اجرا کنید.
6. در صفحه هر محصول یا variation، `productCode` و `sellerItemCode` را وارد و اتصال را فعال کنید.
7. **واحد قیمت فروشگاه (ریال/تومان)** و قوانین قیمت‌گذاری را از منوی «قوانین قیمت‌گذاری» تنظیم کنید.

## نکته مهم درباره واحد قیمت

تکنولایف همه‌ی قیمت‌ها را به **ریال** دریافت می‌کند. اگر قیمت محصولات ووکامرس شما به **تومان** ذخیره می‌شود، در صفحه «قوانین قیمت‌گذاری» گزینه‌ی واحد قیمت را روی «تومان» بگذارید تا افزونه به‌صورت خودکار در ۱۰ ضرب کند و قیمت‌ها هم‌واحدِ بازه‌ی مجاز تکنولایف شوند. در غیر این صورت قیمت‌ها ۱۰ برابر کمتر و خارج از بازه خواهند بود.

## نکته مهم درباره encrypted-secret

طبق مستند، هدر `encrypted-secret` با AES-128-GCM ساخته می‌شود و ورودی الگوریتم «آدرس اندپوینت» است. چون متن دقیق ورودی در مستند مشخص نشده، گزینه‌ای برای تغییر حالت Payload وجود دارد:

- Endpoint Path (پیش‌فرض و منطقی‌ترین)
- Endpoint Path + Query
- Full URL بدون Query
- Full URL + Query
- Path + Body
- Body فقط
- Empty String

اگر API خطای 401 داد، ابتدا `Endpoint Path` و سپس `Endpoint Path + Query` را تست کنید یا مقدار دقیق plaintext را از پشتیبانی تکنولایف بگیرید.


## امکانات نسخه 1.2.0 (جدید)

- **مدیریت پروموشن و تخفیف زمان‌دار:** صفحه‌ی اختصاصی برای بارگذاری پروموشن‌های هر محصول، انتخاب چند تنوع و اعمال تخفیف درصدی یا مبلغی با تاریخ شروع/پایان (تبدیل خودکار به ISO-UTC).
- **داشبورد بای‌باکس:** اسکن وضعیت برنده/بازنده‌ی بای‌باکس، نمایش «قیمت من» در برابر «قیمت برنده» و اختلاف آن‌ها، کارت بازنده‌ها در داشبورد و نشان بای‌باکس در فهرست محصولات.
- **ساخت خودکار تنوع:** بارگذاری فهرست «رنگ/وزن» و «گارانتی» از API و ساخت تنوع جدید بدون نیاز به وارد کردن دستی آیدی‌ها.
- **همگام‌سازی وضعیت سفارش تکنولایف ← ووکامرس:** جدول نگاشت وضعیت‌ها در تنظیمات؛ با تغییر وضعیت سفارش در تکنولایف، وضعیت سفارش ووکامرس به‌صورت خودکار به‌روزرسانی می‌شود.
- **اطلاعات زنده‌ی تنوع در متاباکس محصول:** نمایش لحظه‌ای موجودی، انبارش، «در فرایند فروش»، «در انتظار ارسال/پرداخت»، قیمت نقدی و وضعیت بای‌باکس مستقیماً از تکنولایف.

- بهینه‌سازی دریافت سفارش‌ها: عدم دریافت مجدد جزئیات برای سفارش‌های بدون تغییر وضعیت.

- اصلاحات جزئی: `gmdate` در نام خروجی‌ها، محدودکردن بارگذاری assets فقط به صفحه محصول.
